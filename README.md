# FleetFlow

Open-source delivery logistics platform for e-commerce businesses.

FleetFlow provides a centralized platform for managing deliveries, drivers, routes, and logistics operations.

## Features

- Delivery and fleet management
- Driver and route management
- Real-time delivery tracking
- Logistics dashboards
- Role-based access
- Notifications and integrations

## Tech Stack

Next.js · React · TypeScript · Fastify · PostgreSQL · Prisma · Redis · Docker

## Getting Started

```bash
git clone https://github.com/adithyavishnubg/FleetFlow.git
cd FleetFlow
pnpm install
pnpm dev
